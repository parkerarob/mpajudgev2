# MPA Judge Feedback Survey

Use this short survey after an event or practice run to gather feedback from directors and judges.

Estimated time: 3-5 minutes

## Intro

Thank you for using MPA Judge. We are trying to make the system clearer, faster, and more reliable on event day.

This survey is short on purpose. Please answer based on your real experience, even if the answer is negative.
